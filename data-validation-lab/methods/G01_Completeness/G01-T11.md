# G01-T11 — Completeness | Incomplete Address

## ID
G01-T11

## Group
1 — Completeness

## Type
Incomplete Address — Partial Fields Only

## Live Scenario
A courier company needs to dispatch 800 parcels. The order management system stores address in five fields: AddressLine1, AddressLine2 (optional), City, PostCode, Country. After loading from an e-commerce platform, 34 records have AddressLine1 but no City or PostCode — enough for a human to guess but not enough for the routing API. The dispatch system rejects them. A validation query is needed before each nightly import.

## The Question
> Addresses are stored across multiple fields. A complete, deliverable address needs at minimum: AddressLine1, City, PostCode, and Country.
> **"Find all customer records with an incomplete delivery address. For each, show which specific address component is missing, and score the address completeness out of 4."**

## Table Reference
**Customers** — `schemas/01_Customers.csv`

Address fields: `AddressLine1`, `City`, `PostCode`, `Country`

## Solution Query

```sql
-- Address completeness check
SELECT
    CustomerID,
    FirstName + ' ' + LastName  AS CustomerName,
    AddressLine1,
    City,
    PostCode,
    Country,
    -- Score: 1 point per populated mandatory address field
    (CASE WHEN LEN(LTRIM(RTRIM(ISNULL(AddressLine1,'')))) > 0 THEN 1 ELSE 0 END
   + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(City,        '')))) > 0 THEN 1 ELSE 0 END
   + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(PostCode,    '')))) > 0 THEN 1 ELSE 0 END
   + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Country,     '')))) > 0 THEN 1 ELSE 0 END)
        AS AddressScore,
    -- Which components are missing?
    CONCAT(
        CASE WHEN LEN(LTRIM(RTRIM(ISNULL(AddressLine1,'')))) = 0 THEN 'AddressLine1 ' ELSE '' END,
        CASE WHEN LEN(LTRIM(RTRIM(ISNULL(City,        '')))) = 0 THEN 'City '         ELSE '' END,
        CASE WHEN LEN(LTRIM(RTRIM(ISNULL(PostCode,    '')))) = 0 THEN 'PostCode '     ELSE '' END,
        CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Country,     '')))) = 0 THEN 'Country'       ELSE '' END
    ) AS MissingComponents,
    CASE
        WHEN (CASE WHEN LEN(LTRIM(RTRIM(ISNULL(AddressLine1,'')))) > 0 THEN 1 ELSE 0 END
            + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(City,        '')))) > 0 THEN 1 ELSE 0 END
            + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(PostCode,    '')))) > 0 THEN 1 ELSE 0 END
            + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Country,     '')))) > 0 THEN 1 ELSE 0 END) = 4
        THEN 'Deliverable'
        WHEN (CASE WHEN LEN(LTRIM(RTRIM(ISNULL(AddressLine1,'')))) > 0 THEN 1 ELSE 0 END
            + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(City,        '')))) > 0 THEN 1 ELSE 0 END
            + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(PostCode,    '')))) > 0 THEN 1 ELSE 0 END
            + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Country,     '')))) > 0 THEN 1 ELSE 0 END) >= 2
        THEN 'Partial — needs review'
        ELSE 'Undeliverable — too incomplete'
    END AS DeliveryStatus
FROM Customers
WHERE
    LEN(LTRIM(RTRIM(ISNULL(AddressLine1,'')))) = 0
 OR LEN(LTRIM(RTRIM(ISNULL(City,        '')))) = 0
 OR LEN(LTRIM(RTRIM(ISNULL(PostCode,    '')))) = 0
 OR LEN(LTRIM(RTRIM(ISNULL(Country,     '')))) = 0
ORDER BY AddressScore ASC;

-- Summary by missing component
SELECT
    'AddressLine1 missing' AS Component, COUNT(*) AS RecordCount
FROM Customers WHERE LEN(LTRIM(RTRIM(ISNULL(AddressLine1,'')))) = 0
UNION ALL
SELECT 'City missing',     COUNT(*) FROM Customers WHERE LEN(LTRIM(RTRIM(ISNULL(City,'')))) = 0
UNION ALL
SELECT 'PostCode missing', COUNT(*) FROM Customers WHERE LEN(LTRIM(RTRIM(ISNULL(PostCode,'')))) = 0
UNION ALL
SELECT 'Country missing',  COUNT(*) FROM Customers WHERE LEN(LTRIM(RTRIM(ISNULL(Country,'')))) = 0
ORDER BY RecordCount DESC;
```

## Expected Output

| CustomerID | CustomerName | AddressScore | MissingComponents | DeliveryStatus |
|---|---|---|---|---|
| 9 | Aisha Patel | 2 | City PostCode | Partial — needs review |
| 14 | Carlos Ruiz | 1 | City PostCode Country | Undeliverable — too incomplete |

## Explanation

**CONCAT for a readable missing-component list**
Rather than returning one column per address field, CONCAT builds a single string listing only the missing components. This is easier for an operations team to action — they see "City PostCode" and know exactly what to chase, without reading across six columns.

**Address completeness is domain-specific**
For a courier, PostCode + Country is the minimum for routing. For a marketing team, City alone may be enough for regional segmentation. The score threshold and which fields count as mandatory should be configured per use case, not hard-coded as a single universal rule.

**AddressLine2 is intentionally excluded**
AddressLine2 (flat number, floor, suite) is optional in most address standards. Flagging its absence would produce false positives for every customer without a second address line. Optional fields should be excluded from completeness scoring unless there is a specific business rule requiring them.

## Severity
**High** — An undeliverable address on a physical goods order means a failed delivery, a customer complaint, and a return shipping cost. For regulated industries (financial statements, legal notices), an incomplete address may be a compliance failure.
