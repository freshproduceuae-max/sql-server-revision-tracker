# G01-T05 — Completeness | Partial Record

## ID
G01-T05

## Group
1 — Completeness

## Type
Partial Record — Some Required Fields Missing

## Live Scenario
A healthcare provider loads patient registration forms daily. Some forms are submitted with only the patient's name and date of birth — the GP code, insurance number, and contact details are filled in later. Records with fewer than 4 of 6 mandatory fields populated are considered incomplete and must not be passed to the billing system. The data team needs a completeness score per record to enforce the threshold.

## The Question
> Your intake process accepts partial records but the billing system requires all 6 mandatory fields to be populated.
> **"Score every customer record by how many mandatory fields are complete. Flag any record with a completeness score below 4 out of 6 as 'Incomplete' and return them ranked worst first."**

## Table Reference
**Customers** — `schemas/01_Customers.csv`

Mandatory fields: `FirstName`, `LastName`, `Email`, `Phone`, `DOB`, `Country`

## Solution Query

```sql
-- Score each record by mandatory field completeness
WITH CompletenessScore AS (
    SELECT
        CustomerID,
        FirstName,
        LastName,
        Email,
        Phone,
        DOB,
        Country,
        -- Count how many mandatory fields are populated (not NULL, not blank)
        (CASE WHEN LEN(LTRIM(RTRIM(ISNULL(FirstName,'')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(LastName, '')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Email,    '')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Phone,    '')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN DOB     IS NOT NULL                          THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Country,  '')))) > 0 THEN 1 ELSE 0 END)
            AS FieldsPopulated,
        6   AS TotalMandatoryFields
    FROM Customers
)
SELECT
    CustomerID,
    FirstName,
    LastName,
    Email,
    Phone,
    CAST(DOB AS VARCHAR(10)) AS DOB,
    Country,
    FieldsPopulated,
    TotalMandatoryFields,
    CAST(FieldsPopulated * 100.0 / TotalMandatoryFields AS DECIMAL(5,1)) AS CompletenessPct,
    CASE
        WHEN FieldsPopulated = TotalMandatoryFields THEN 'Complete'
        WHEN FieldsPopulated >= 4                   THEN 'Acceptable'
        WHEN FieldsPopulated >= 2                   THEN 'Incomplete'
        ELSE                                             'Critical — nearly empty'
    END AS CompletenessStatus
FROM CompletenessScore
WHERE FieldsPopulated < TotalMandatoryFields   -- only return records with at least one gap
ORDER BY FieldsPopulated ASC, CustomerID;

-- Summary: distribution of completeness scores
SELECT
    FieldsPopulated,
    COUNT(*) AS RecordCount,
    CAST(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER () AS DECIMAL(5,1)) AS PctOfTotal
FROM (
    SELECT
        (CASE WHEN LEN(LTRIM(RTRIM(ISNULL(FirstName,'')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(LastName, '')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Email,    '')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Phone,    '')))) > 0 THEN 1 ELSE 0 END
       + CASE WHEN DOB     IS NOT NULL                          THEN 1 ELSE 0 END
       + CASE WHEN LEN(LTRIM(RTRIM(ISNULL(Country,  '')))) > 0 THEN 1 ELSE 0 END)
            AS FieldsPopulated
    FROM Customers
) s
GROUP BY FieldsPopulated
ORDER BY FieldsPopulated;
```

## Expected Output

| CustomerID | FirstName | FieldsPopulated | CompletenessPct | CompletenessStatus |
|---|---|---|---|---|
| 16 | N/A | 1 | 16.7% | Critical — nearly empty |
| 3 | Mohammed | 4 | 66.7% | Acceptable |
| 5 | Chen | 5 | 83.3% | Acceptable |

## Explanation

**Building a completeness score per row**
Each CASE WHEN returns 1 (field is populated) or 0 (field is missing). Summing them gives the count of populated mandatory fields. This is the standard pattern for a per-record completeness score — it works across any number of columns.

**Why a CTE rather than repeating the expression**
The score expression is long. Writing it once in the CTE and referencing `FieldsPopulated` in the outer query avoids repeating 6 CASE WHEN blocks in both SELECT and WHERE, reducing the risk of inconsistency between the displayed value and the filter.

**SUM() OVER () for the percentage in the summary**
`SUM(COUNT(*)) OVER ()` computes the grand total of all records as a window function, allowing the percentage to be calculated in a single pass without a subquery or a separate COUNT.

## Severity
**High** — Partial records that reach downstream systems cause failed API calls, incomplete invoices, and broken customer journeys. A completeness score threshold gate prevents them from progressing.
