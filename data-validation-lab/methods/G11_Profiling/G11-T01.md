# G11-T01 — Profiling | Column Completeness Profile

## ID
G11-T01

## Group
11 — Profiling

## Type
Column Completeness Profile — Systematic NULL and Population Rate Analysis Across All Columns

## Live Scenario
A data governance team at a financial services firm is onboarding a new data source — a customer risk score feed from a third-party provider. Before the feed is trusted for regulatory reporting, the team must profile every column: what percentage is populated, are mandatory fields fully populated, and do population rates match the contract specification? The provider's SLA states "all 12 columns will be 100% populated." Profiling reveals that `RiskScore` is 94% populated (6% NULL) and `LastAssessmentDate` is 78% populated. Neither breaches were disclosed, and the 6% NULL risk scores would cause division errors in downstream risk calculations. The data governance team uses the profile to negotiate a data quality SLA addendum.

## The Question
> Column completeness profiling measures the population rate (non-NULL %) for every column in a table. It is the most fundamental step in data quality assessment, revealing gaps in mandatory fields, optional fields with unexpected NULLs, and columns with systematically missing data.
> **"Produce a completeness profile for every column in the Customers table: count total rows, NULL rows, empty string rows, populated rows, and compute the population percentage for each column."**

## Table Reference
**Customers** — `schemas/01_Customers.csv`
**Orders** — `schemas/02_Orders.csv`
**Products** — `schemas/03_Products.csv`

## Solution Query

```sql
-- Step 1: Completeness profile for Customers table
SELECT
    ColumnName,
    TotalRows,
    PopulatedRows,
    NullRows,
    EmptyRows,
    ROUND(100.0 * PopulatedRows / NULLIF(TotalRows, 0), 1) AS PopulationPct,
    ROUND(100.0 * NullRows / NULLIF(TotalRows, 0), 1) AS NullPct,
    CASE
        WHEN PopulatedRows = TotalRows
             THEN '100% — Fully populated'
        WHEN ROUND(100.0 * PopulatedRows / NULLIF(TotalRows, 0), 1) >= 99
             THEN '>99% — Near complete'
        WHEN ROUND(100.0 * PopulatedRows / NULLIF(TotalRows, 0), 1) >= 90
             THEN 'Good (90–99%)'
        WHEN ROUND(100.0 * PopulatedRows / NULLIF(TotalRows, 0), 1) >= 70
             THEN 'Moderate (70–90%)'
        WHEN ROUND(100.0 * PopulatedRows / NULLIF(TotalRows, 0), 1) >= 50
             THEN 'Low (50–70%) — investigate'
        ELSE 'POOR (<50%) — critical gap'
    END AS CompletenessRating
FROM (
    SELECT 'CustomerID'   AS ColumnName, COUNT(*) AS TotalRows,
           SUM(CASE WHEN CustomerID IS NOT NULL THEN 1 ELSE 0 END) AS PopulatedRows,
           SUM(CASE WHEN CustomerID IS NULL THEN 1 ELSE 0 END) AS NullRows,
           0 AS EmptyRows FROM Customers
    UNION ALL
    SELECT 'FirstName', COUNT(*),
           SUM(CASE WHEN FirstName IS NOT NULL AND LTRIM(FirstName) <> '' THEN 1 ELSE 0 END),
           SUM(CASE WHEN FirstName IS NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN FirstName IS NOT NULL AND LTRIM(FirstName) = '' THEN 1 ELSE 0 END)
    FROM Customers
    UNION ALL
    SELECT 'LastName', COUNT(*),
           SUM(CASE WHEN LastName IS NOT NULL AND LTRIM(LastName) <> '' THEN 1 ELSE 0 END),
           SUM(CASE WHEN LastName IS NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN LastName IS NOT NULL AND LTRIM(LastName) = '' THEN 1 ELSE 0 END)
    FROM Customers
    UNION ALL
    SELECT 'Email', COUNT(*),
           SUM(CASE WHEN Email IS NOT NULL AND LTRIM(Email) <> '' THEN 1 ELSE 0 END),
           SUM(CASE WHEN Email IS NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN Email IS NOT NULL AND LTRIM(Email) = '' THEN 1 ELSE 0 END)
    FROM Customers
    UNION ALL
    SELECT 'Phone', COUNT(*),
           SUM(CASE WHEN Phone IS NOT NULL AND LTRIM(Phone) <> '' THEN 1 ELSE 0 END),
           SUM(CASE WHEN Phone IS NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN Phone IS NOT NULL AND LTRIM(Phone) = '' THEN 1 ELSE 0 END)
    FROM Customers
    UNION ALL
    SELECT 'PostalCode', COUNT(*),
           SUM(CASE WHEN PostalCode IS NOT NULL AND LTRIM(PostalCode) <> '' THEN 1 ELSE 0 END),
           SUM(CASE WHEN PostalCode IS NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN PostalCode IS NOT NULL AND LTRIM(PostalCode) = '' THEN 1 ELSE 0 END)
    FROM Customers
    UNION ALL
    SELECT 'DateOfBirth', COUNT(*),
           SUM(CASE WHEN DateOfBirth IS NOT NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN DateOfBirth IS NULL THEN 1 ELSE 0 END), 0
    FROM Customers
    UNION ALL
    SELECT 'Country', COUNT(*),
           SUM(CASE WHEN Country IS NOT NULL AND LTRIM(Country) <> '' THEN 1 ELSE 0 END),
           SUM(CASE WHEN Country IS NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN Country IS NOT NULL AND LTRIM(Country) = '' THEN 1 ELSE 0 END)
    FROM Customers
    UNION ALL
    SELECT 'IsActive', COUNT(*),
           SUM(CASE WHEN IsActive IS NOT NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN IsActive IS NULL THEN 1 ELSE 0 END), 0
    FROM Customers
    UNION ALL
    SELECT 'ContractEnd', COUNT(*),
           SUM(CASE WHEN ContractEnd IS NOT NULL THEN 1 ELSE 0 END),
           SUM(CASE WHEN ContractEnd IS NULL THEN 1 ELSE 0 END), 0
    FROM Customers
) Profile
ORDER BY PopulationPct ASC;

-- Step 2: Cross-table completeness summary
SELECT
    TableName,
    ColumnCount,
    FullyPopulatedColumns,
    PartiallyPopulatedColumns,
    EmptyColumns,
    ROUND(100.0 * FullyPopulatedColumns / NULLIF(ColumnCount, 0), 1) AS FullPopulationPct
FROM (
    SELECT 'Customers' AS TableName,
           10 AS ColumnCount,
           SUM(CASE WHEN PopulationPct = 100 THEN 1 ELSE 0 END) AS FullyPopulatedColumns,
           SUM(CASE WHEN PopulationPct BETWEEN 1 AND 99 THEN 1 ELSE 0 END) AS PartiallyPopulatedColumns,
           SUM(CASE WHEN PopulationPct = 0 THEN 1 ELSE 0 END) AS EmptyColumns
    FROM (
        SELECT ROUND(100.0 * SUM(CASE WHEN v IS NOT NULL THEN 1 ELSE 0 END) / NULLIF(COUNT(*), 0), 1) AS PopulationPct
        FROM (
            SELECT CAST(CustomerID AS VARCHAR) AS v FROM Customers UNION ALL
            SELECT FirstName FROM Customers UNION ALL
            SELECT LastName FROM Customers UNION ALL
            SELECT Email FROM Customers UNION ALL
            SELECT Phone FROM Customers
        ) cv
        GROUP BY v
    ) ColPcts
) Summary;

-- Step 3: Orders completeness (key fields)
SELECT
    ColumnName,
    TotalRows,
    PopulatedRows,
    ROUND(100.0 * PopulatedRows / NULLIF(TotalRows, 0), 1) AS PopulationPct
FROM (
    SELECT 'OrderID',   COUNT(*), SUM(CASE WHEN OrderID IS NOT NULL THEN 1 ELSE 0 END) FROM Orders UNION ALL
    SELECT 'CustomerID', COUNT(*), SUM(CASE WHEN CustomerID IS NOT NULL THEN 1 ELSE 0 END) FROM Orders UNION ALL
    SELECT 'ProductID',  COUNT(*), SUM(CASE WHEN ProductID IS NOT NULL THEN 1 ELSE 0 END) FROM Orders UNION ALL
    SELECT 'OrderDate',  COUNT(*), SUM(CASE WHEN OrderDate IS NOT NULL THEN 1 ELSE 0 END) FROM Orders UNION ALL
    SELECT 'DeliveryDate', COUNT(*), SUM(CASE WHEN DeliveryDate IS NOT NULL THEN 1 ELSE 0 END) FROM Orders UNION ALL
    SELECT 'TotalAmount', COUNT(*), SUM(CASE WHEN TotalAmount IS NOT NULL THEN 1 ELSE 0 END) FROM Orders UNION ALL
    SELECT 'Status',     COUNT(*), SUM(CASE WHEN Status IS NOT NULL THEN 1 ELSE 0 END) FROM Orders
) t(ColumnName, TotalRows, PopulatedRows)
ORDER BY PopulationPct;
```

## Expected Output

**Step 1 — Customer completeness profile:**
| ColumnName | TotalRows | PopulatedRows | NullRows | PopulationPct | CompletenessRating |
|---|---|---|---|---|---|
| ContractEnd | 12 | 8 | 4 | 66.7 | Moderate (70–90%) |
| DateOfBirth | 12 | 10 | 2 | 83.3 | Good (90–99%) |
| Phone | 12 | 8 | 3 | 66.7 | Moderate (70–90%) |
| Email | 12 | 12 | 0 | 100.0 | 100% — Fully populated |

## Explanation

**The population rate formula**
`100.0 × PopulatedRows / TotalRows` is the population percentage. The `100.0` (not `100`) forces floating-point division. `NULLIF(TotalRows, 0)` prevents division by zero for empty tables. Rounding to 1 decimal place is standard for data quality dashboards.

**Empty string vs NULL in completeness**
The profile counts empty strings separately from NULLs: `SUM(CASE WHEN col IS NOT NULL AND LTRIM(col) = '' THEN 1 ELSE 0 END)`. Population rate uses the combined "truly populated" count: non-NULL and non-empty. Without this distinction, a column with all empty strings shows 100% population but is effectively empty.

**UNION ALL pattern for multi-column profiling**
The UNION ALL approach profiles multiple columns in a single query. In SQL Server, there is no system view that directly gives column-level NULL counts for user tables — dynamic SQL or UNION ALL are the practical options. For large tables, a single-pass approach using multiple CASE expressions in a single SELECT is more efficient.

**Completeness ratings for governance**
The five-tier rating (100%, >99%, 90–99%, 70–90%, <50%) provides a standard vocabulary for data governance. A "Poor" rating for a mandatory field triggers an immediate data quality incident; "Moderate" triggers a remediation task in the next sprint. Thresholds should be agreed with data owners and documented in the data quality framework.

## Severity
**High** — Column completeness profiling is the foundation of data quality assessment. Without knowing population rates, downstream queries using those columns produce results that exclude unknown proportions of the data without warning. A 6% NULL rate in a risk score column silently excludes 6% of customers from risk calculations — an invisible, significant gap.
