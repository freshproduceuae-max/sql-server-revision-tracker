# G11-T08 — Profiling | Data Density and Sparsity Profile

## ID
G11-T08

## Group
11 — Profiling

## Type
Data Density and Sparsity Profile — Measuring How Completely a Table Is Populated Across All Columns

## Live Scenario
A data governance team inherits a CRM database from an acquired company. Before migrating it into their central data warehouse, they run a density profile across all 47 columns. The result is striking: 31 of 47 columns have less than 10% population — they are effectively empty. The 16 well-populated columns (>80%) are the core transactional fields. Eight columns have exactly 0% population: they were added in a schema migration three years ago but never populated by the application. Three columns have exactly 100% population but on closer inspection contain the placeholder text "N/A" or "Unknown" — technically populated but informationally empty. The density profile gives the migration team a ranked list: migrate the 16 dense columns first, archive the 8 empty columns, and investigate the 23 sparse columns individually.

## The Question
> A data density profile measures what fraction of rows are populated (non-NULL, non-empty) for each column. A density (or sparsity) profile identifies columns that are structurally empty, partially populated, or fully dense. This guides decisions about which columns to include in downstream models, reports, and migrations.
> **"Produce a complete density profile of the Orders table: for every column, show the total row count, populated count, NULL count, empty-string count, and density percentage — then rank columns by density and flag any that are structurally sparse or suspicious."**

## Table Reference
**Orders** — `schemas/02_Orders.csv`
**Customers** — `schemas/01_Customers.csv`

## Solution Query

```sql
-- Step 1: Full density profile for Orders table
WITH OrderDensity AS (
    SELECT
        'OrderID'      AS ColName, COUNT(*) AS TotalRows,
        COUNT(OrderID) AS PopulatedCount,
        SUM(CASE WHEN OrderID IS NULL THEN 1 ELSE 0 END) AS NullCount,
        0 AS EmptyStringCount
    FROM Orders
    UNION ALL
    SELECT 'CustomerID', COUNT(*), COUNT(CustomerID),
        SUM(CASE WHEN CustomerID IS NULL THEN 1 ELSE 0 END), 0
    FROM Orders
    UNION ALL
    SELECT 'ProductID', COUNT(*), COUNT(ProductID),
        SUM(CASE WHEN ProductID IS NULL THEN 1 ELSE 0 END), 0
    FROM Orders
    UNION ALL
    SELECT 'OrderDate', COUNT(*), COUNT(OrderDate),
        SUM(CASE WHEN OrderDate IS NULL THEN 1 ELSE 0 END), 0
    FROM Orders
    UNION ALL
    SELECT 'DeliveryDate', COUNT(*), COUNT(DeliveryDate),
        SUM(CASE WHEN DeliveryDate IS NULL THEN 1 ELSE 0 END), 0
    FROM Orders
    UNION ALL
    SELECT 'TotalAmount', COUNT(*), COUNT(TotalAmount),
        SUM(CASE WHEN TotalAmount IS NULL THEN 1 ELSE 0 END), 0
    FROM Orders
    UNION ALL
    SELECT 'Status', COUNT(*), COUNT(Status),
        SUM(CASE WHEN Status IS NULL THEN 1 ELSE 0 END),
        SUM(CASE WHEN Status = '' THEN 1 ELSE 0 END)
    FROM Orders
    UNION ALL
    SELECT 'XMLData', COUNT(*), COUNT(XMLData),
        SUM(CASE WHEN XMLData IS NULL THEN 1 ELSE 0 END),
        SUM(CASE WHEN CAST(XMLData AS NVARCHAR(MAX)) = '' THEN 1 ELSE 0 END)
    FROM Orders
    UNION ALL
    SELECT 'Metadata', COUNT(*), COUNT(Metadata),
        SUM(CASE WHEN Metadata IS NULL THEN 1 ELSE 0 END),
        SUM(CASE WHEN Metadata = '' THEN 1 ELSE 0 END)
    FROM Orders
    UNION ALL
    SELECT 'Notes', COUNT(*), COUNT(Notes),
        SUM(CASE WHEN Notes IS NULL THEN 1 ELSE 0 END),
        SUM(CASE WHEN LTRIM(RTRIM(Notes)) = '' THEN 1 ELSE 0 END)
    FROM Orders
    UNION ALL
    SELECT 'AttachmentPath', COUNT(*), COUNT(AttachmentPath),
        SUM(CASE WHEN AttachmentPath IS NULL THEN 1 ELSE 0 END),
        SUM(CASE WHEN LTRIM(RTRIM(AttachmentPath)) = '' THEN 1 ELSE 0 END)
    FROM Orders
)
SELECT
    ColName,
    TotalRows,
    PopulatedCount,
    NullCount,
    EmptyStringCount,
    TotalRows - PopulatedCount - EmptyStringCount AS MissingTotal,
    ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) AS DensityPct,
    ROUND(100.0 * NullCount / NULLIF(TotalRows, 0), 1) AS NullPct,
    -- Density tier classification
    CASE
        WHEN PopulatedCount = 0
             THEN 'EMPTY: No values — column may be unused'
        WHEN ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) = 100.0
             THEN 'COMPLETE: Fully populated'
        WHEN ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) >= 95.0
             THEN 'NEAR-COMPLETE: ≥95% populated'
        WHEN ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) >= 80.0
             THEN 'DENSE: ≥80% populated'
        WHEN ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) >= 50.0
             THEN 'MODERATE: 50-79% populated'
        WHEN ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) >= 10.0
             THEN 'SPARSE: 10-49% populated — investigate'
        ELSE 'VERY SPARSE: <10% populated — consider dropping'
    END AS DensityTier,
    -- Required vs optional column guidance
    CASE
        WHEN ColName IN ('OrderID', 'CustomerID', 'OrderDate', 'TotalAmount', 'Status')
             AND PopulatedCount < TotalRows
             THEN 'ALERT: Mandatory business field has NULLs'
        WHEN ColName IN ('Notes', 'AttachmentPath', 'Metadata', 'XMLData')
             AND ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) < 50.0
             THEN 'LOW USAGE: Optional field sparsely used'
        ELSE 'OK'
    END AS BusinessAlert
FROM OrderDensity
ORDER BY DensityPct DESC;

-- Step 2: Row-level completeness score — how many columns are populated per row?
SELECT
    OrderID,
    -- Count populated fields per row
    (CASE WHEN OrderID      IS NOT NULL THEN 1 ELSE 0 END +
     CASE WHEN CustomerID   IS NOT NULL THEN 1 ELSE 0 END +
     CASE WHEN ProductID    IS NOT NULL THEN 1 ELSE 0 END +
     CASE WHEN OrderDate    IS NOT NULL THEN 1 ELSE 0 END +
     CASE WHEN DeliveryDate IS NOT NULL THEN 1 ELSE 0 END +
     CASE WHEN TotalAmount  IS NOT NULL THEN 1 ELSE 0 END +
     CASE WHEN Status       IS NOT NULL AND Status <> '' THEN 1 ELSE 0 END +
     CASE WHEN Notes        IS NOT NULL AND LTRIM(RTRIM(Notes)) <> '' THEN 1 ELSE 0 END)
        AS FieldsPopulated,
    8 AS TotalFields,
    ROUND(100.0 *
     (CASE WHEN OrderID      IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN CustomerID   IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN ProductID    IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN OrderDate    IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN DeliveryDate IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN TotalAmount  IS NOT NULL THEN 1 ELSE 0 END +
      CASE WHEN Status       IS NOT NULL AND Status <> '' THEN 1 ELSE 0 END +
      CASE WHEN Notes        IS NOT NULL AND LTRIM(RTRIM(Notes)) <> '' THEN 1 ELSE 0 END)
     / 8.0, 1) AS RowCompletenessPct
FROM Orders
ORDER BY RowCompletenessPct ASC;

-- Step 3: Table-level density summary
SELECT
    ROUND(AVG(DensityPct), 1) AS AvgTableDensity,
    MIN(DensityPct) AS MinColumnDensity,
    MAX(DensityPct) AS MaxColumnDensity,
    SUM(CASE WHEN DensityPct = 0 THEN 1 ELSE 0 END) AS EmptyColumns,
    SUM(CASE WHEN DensityPct = 100 THEN 1 ELSE 0 END) AS CompleteColumns,
    SUM(CASE WHEN DensityPct BETWEEN 1 AND 49 THEN 1 ELSE 0 END) AS SparseColumns,
    COUNT(*) AS TotalColumns
FROM (
    SELECT
        ColName,
        ROUND(100.0 * PopulatedCount / NULLIF(TotalRows, 0), 1) AS DensityPct
    FROM (
        SELECT 'OrderID'      AS ColName, COUNT(*) TotalRows, COUNT(OrderID)      PopulatedCount FROM Orders UNION ALL
        SELECT 'CustomerID',  COUNT(*), COUNT(CustomerID)  FROM Orders UNION ALL
        SELECT 'ProductID',   COUNT(*), COUNT(ProductID)   FROM Orders UNION ALL
        SELECT 'OrderDate',   COUNT(*), COUNT(OrderDate)   FROM Orders UNION ALL
        SELECT 'DeliveryDate',COUNT(*), COUNT(DeliveryDate)FROM Orders UNION ALL
        SELECT 'TotalAmount', COUNT(*), COUNT(TotalAmount) FROM Orders UNION ALL
        SELECT 'Status',      COUNT(*), COUNT(Status)      FROM Orders UNION ALL
        SELECT 'Notes',       COUNT(*), COUNT(Notes)       FROM Orders UNION ALL
        SELECT 'AttachmentPath',COUNT(*),COUNT(AttachmentPath) FROM Orders UNION ALL
        SELECT 'Metadata',    COUNT(*), COUNT(Metadata)    FROM Orders UNION ALL
        SELECT 'XMLData',     COUNT(*), COUNT(XMLData)     FROM Orders
    ) D
) Summary;
```

## Explanation

**Column-level vs row-level density**
Step 1 profiles each column independently (how many rows have a value?). Step 2 profiles each row (how many columns are populated?). Both perspectives matter: a column with 80% density looks healthy until you find those 20% NULLs are all in the same 5 rows — rows that also have NULLs in 6 other columns, indicating a batch import failure for those specific records.

**Mandatory vs optional field classification**
The `BusinessAlert` column distinguishes between mandatory fields (OrderID, CustomerID, TotalAmount) where any NULL is a data integrity failure, and optional fields (Notes, AttachmentPath) where sparse population is by design. A single query can check both classes simultaneously.

**Density tier cutoffs**
The five-tier system (Empty/Sparse/Moderate/Dense/Complete) gives a decision framework: Empty columns (0%) are candidates for removal; Sparse columns (1–49%) require investigation — are they optional fields, conditional fields, or migration failures? Dense columns (≥80%) are safe for analysis. Near-complete columns (≥95%) are practically dense for most use cases.

**Table-level density score**
Step 3's aggregate — average density across all columns — gives a single number representing the table's overall data quality health. A table with average density of 62% has significant optional fields or chronic data entry gaps; a table at 97% is well-maintained. This score can be tracked over time to detect regression.

## Severity
**Medium** — Data sparsity directly limits analytical value: a column that is 10% populated cannot be used as a model feature, a filter criterion, or a join key without producing highly skewed results. Density profiling identifies which columns are analytically viable and which require remediation before use.
