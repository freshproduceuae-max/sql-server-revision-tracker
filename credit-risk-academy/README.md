# Commercial & Corporate Credit Risk Academy

**Audience:** Experienced Banking Business Analyst → Credit Risk Expert
**Scope:** End-to-end commercial and corporate lending lifecycle
**Method:** First principles + practical banking experience + iterative Japanese-style reinforcement
**Modules:** 47 core modules + progressive case studies

---

## How This Academy Works

Every module follows the same 15-component structure:

| # | Component | What It Gives You |
|---|-----------|-------------------|
| 1 | Business Purpose | Why banks do this |
| 2 | Accounting Concepts | The financial reporting context |
| 3 | Financial Concepts | The economic logic |
| 4 | Statistical Concepts | The quantitative foundations |
| 5 | Regulatory Framework | Basel, IFRS 9, local rules |
| 6 | Data Required | Inputs, sources, formats |
| 7 | How Analysts Actually Work | Real bank workflow |
| 8 | Excel Implementation | Spreadsheet models |
| 9 | SQL Implementation | Database queries |
| 10 | Python Implementation | Code and models |
| 11 | Interview Questions | Questions you will be asked |
| 12 | Common Mistakes | What analysts get wrong |
| 13 | Case Studies | Progressive real-world exercises |
| 14 | Iterative Reinforcement | Building on prior modules |
| 15 | Source Material | Real annual reports and regulatory publications |
