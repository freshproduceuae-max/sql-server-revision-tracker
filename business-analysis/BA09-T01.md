# BA09-T01 — Underlying Competencies | Analytical Thinking and Problem Solving

## ID
BA09-T01

## Chapter
9 — Underlying Competencies

## Live Scenario
Complaints about a billing system rise 300% in a month. The obvious explanation is the release that shipped three weeks earlier. Fixing the release changes nothing.

## The Question
> How do you structure the investigation so you find the cause rather than the most available explanation?

## Approach
1. State the problem precisely — which complaints, from whom, starting exactly when.
2. Test the timing assumption against the data before accepting the release as cause.
3. Generate competing hypotheses and identify what evidence would discriminate between them.
4. Trace to root cause rather than stopping at the first plausible explanation.

## Deliverables
- A structured problem statement with evidence
- A root cause analysis with the discarded hypotheses recorded

## Tools
- Fishbone diagrams in Lucidchart or Visio
- Five Whys in Miro
- SQL and Excel for the underlying data

## Common Pitfall
Anchoring on the first plausible cause. Coincident timing is not causation, and a fix aimed at the wrong cause costs twice — once to build, once to discover it did not work.

## Interview Angle
Have a story where your first hypothesis was wrong and you found out. Candidates who only tell success stories read as untested.
