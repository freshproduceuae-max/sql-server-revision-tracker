# BA08-T02 — Solution Evaluation | Analysing Performance Measures

## ID
BA08-T02

## Chapter
8 — Solution Evaluation

## Live Scenario
Processing time fell 30% overall. Broken down by region, one region improved 60% and another got 15% slower. The overall figure conceals both.

## The Question
> How do you analyse measures so that averages do not hide the effects that matter?

## Approach
1. Disaggregate by the dimensions where behaviour plausibly differs — region, product, user group, volume band.
2. Look for variance and distribution, not only central tendency.
3. Investigate the outliers rather than dismissing them; they usually explain the mechanism.
4. Separate correlation from cause before attributing improvement to the change.

## Deliverables
- A disaggregated performance analysis with identified variance
- Hypotheses explaining outlier segments

## Tools
- Power BI or Tableau for segmentation
- SQL for cohort extraction
- Excel for distribution analysis

## Common Pitfall
Reporting the average. It is the single most reliable way to miss that a change helped one group and harmed another.

## Interview Angle
If you have a data validation background, say so — this is the same reasoning as profiling before trusting an aggregate.
