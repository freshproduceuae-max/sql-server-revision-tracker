# BA08-T05 — Solution Evaluation | Recommending Actions to Increase Solution Value

## ID
BA08-T05

## Chapter
8 — Solution Evaluation

## Live Scenario
Evaluation shows the solution delivers 60% of the expected benefit. Options are to invest further, accept the shortfall, change the surrounding process, or retire the solution.

## The Question
> How do you build a recommendation that is honest about a shortfall without triggering a defensive reaction that blocks action?

## Approach
1. Present the evidence before the recommendation so the conclusion is visibly derived, not asserted.
2. Separate what the solution caused from what the environment caused.
3. Give options with cost and expected uplift for each, including doing nothing further.
4. State what you would need to know to be more confident, rather than overclaiming.

## Deliverables
- An evidence-led recommendation with costed options
- A stated confidence level and information gaps

## Tools
- Power BI for the evidence pack
- Excel for option costing
- PowerPoint for the recommendation

## Common Pitfall
Leading with the recommendation. If the audience disagrees with the conclusion before seeing the evidence, they will attack the evidence rather than weigh it.

## Interview Angle
Delivering unwelcome findings is a standard senior interview theme. Evidence-before-conclusion is the structural answer.
