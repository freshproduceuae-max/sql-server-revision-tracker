# BA06-T02 — Strategy Analysis | Defining the Future State

## ID
BA06-T02

## Chapter
6 — Strategy Analysis

## Live Scenario
A future state is described as 'a modern, integrated, customer-centric platform'. Two directors read this as two different systems, and both believe the board approved theirs.

## The Question
> How do you define a future state specific enough to be buildable but not so specific that it presumes a solution?

## Approach
1. Describe the future state in terms of capabilities and outcomes, not products.
2. State the measurable targets that define success, tied to the current-state baseline.
3. Define scope boundaries explicitly — what the change will not address.
4. Validate the future state against the business need to check it actually closes the gap.

## Deliverables
- A future state description with measurable targets
- An explicit out-of-scope statement

## Tools
- Lucidchart for capability models
- Excel for target metrics
- Word for the future state definition

## Common Pitfall
Adjective-driven future states. 'Modern' and 'seamless' cannot be tested, so they cannot be delivered or disputed — which is precisely why they survive review.

## Interview Angle
Be able to convert a vague aspiration into a measurable target on the spot. Interviewers use this to test rigour.
